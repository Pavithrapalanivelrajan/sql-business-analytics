# SQL Business Analytics Project

This project contains SQL scripts for analyzing a sample e-commerce database (customers, orders, products).

## What it does

- Creates a relational database with 3 tables (Customers, Products, Orders)
- Inserts sample data
- Runs 4 analytical queries:
  - Top customers by revenue
  - Monthly revenue trend
  - Average order value by category
  - Best and worst selling products

## How to use

1. Install MySQL and open MySQL Workbench
2. Run the entire script to create database and tables
3. Run individual queries to get business insights

## Tools

- MySQL Server
- MySQL Workbench
